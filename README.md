# 案件起诉状答辩状示范文本

## 相关规定

- `法〔2025〕82号` 2025年5月28日，《关于印发部分案件起诉状答辩状示范文本的通知》。发布示范文本囊括刑事（自诉）、民事、商事、知识产权、海事、行政、环境资源、国家赔偿、执行等9个领域、合计67类常见多发纠纷，其中新增56类；于2025年7月14日起在全国法院全面推广使用。
- `法〔2024〕46号` 2024年3月4日，《关于印发部分案件民事起诉状、答辩状示范文本（试行）的通知》。发布第一批11类试行示范文本；自2024年3月4日起试行，试行期一年。
- `法〔2020〕261号` 2020年9月30日，关于印发《民事诉讼程序繁简分流改革试点相关诉讼文书样式》的通知。2020年11月1日起正式施。
- `法〔2016〕221号` 2016年6月28日，最高人民法院关于印发《人民法院民事裁判文书制作规范》《民事诉讼文书样式》的通知。2016年8月1日起正式施行。
